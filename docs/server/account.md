# 服务器财务

## 赞助支持服务器
**我们是完全的公益服务器，**且承诺玩家赞助的金额会全款用在服务器上。我们目前没有任何盈利措施，在 Comet 二周目里，我们完全剔除了所有充值入口和广告，玩家赞助将不再获得任何物品。如果屏幕前的您喜欢我们的服务器，可以**在有能力的前提下**考虑向我们[赞助](https://www.mccomet.top/donate.html)，以支持服务器运营。在此感谢您。

::: info
您可访问服务器官网的[赞助支持](https://www.mccomet.top/donate.html)页面前去赞助，具体赞助规则已在页面中提供。您的支持就是我们前进的动力！
:::

### 成为我们的赞助者

感谢您对 Comet 服务器的支持！作为完全公益的服务器，我们承诺将您的赞助金额全额用于服务器运营维护。

#### 赞助说明
1. 我们是**完全的公益服务器**，无任何盈利措施。
2. 赞助将不再获得任何游戏内物品。
3. 所有财务明细公开透明，可在[财务报表](https://www.kdocs.cn/l/ctLdxYDpCWw1)查看。

#### 赞助福利

虽然我们不提供游戏内物品回报，但您的支持将为您带来以下荣誉：

| 福利项目 | 说明 |
|---------|------|
| 群头衔定制 | 可定制6字以内的专属群头衔（QQ群等级60级以上也可申请） |
| 赞助者展示 | **赞助金额≥10元**，您的名字将永久展示在**官网赞助页面**与**文档站主页**的赞助者列表中 |

#### 赞助方式

您可以通过以下方式向我们提供支持：

- **扫码赞助**：访问服务器官网的[赞助支持](https://www.mccomet.top/donate.html)页面，选择适合您的方式进行赞助。

:::warning 注意事项
1. 请在**有能力的前提下**考虑赞助，切勿影响正常生活。
2. 赞助属于自愿行为，我们不会主动索要。
3. 如有任何疑问，可联系服务器管理员。
:::

感谢每一位支持 Comet 服务器的玩家，您的每一份帮助都是我们前进的动力！
