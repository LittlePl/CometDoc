# Comet 生存服务器 <Badge type="info" text="一周目" />
> 开服时间：2022.2.16 ~ 2025.1.29，历时1078天
:::tip
以下所有内容只适用于 Comet 生存服务器**一周目**。
:::

## 简介
Comet 生存服务器作为 Comet 群组服务器中的**核心服务器**，从**混沌之初**就已开始运行，至今已有**超过数百个玩家**在这里安营扎寨。

该服务器主要以**生存玩法**为主，玩家在进入服务器后仅需**即刻开始游玩**，然后开始体验**原生的生存乐趣**。

我们极其注重玩家的**游戏体验**。在不影响服务器性能和游戏玩法的前提下，Comet 生存服务器**配备大量实用性插件**，有利于帮助玩家的生存与发展，包括玩家间传送、定点传送、领地系统、公会系统、经济系统、移动光源、生存飞行等，并都集成在一个强大的**菜单**中。

与大多数纯生存服务器不同，Comet 生存服务器**支持让玩家获得 Xbox 成就**。通过完成每一个成就，您可为你的 Xbox 账户获得相应的**游戏点数**。游戏点数在游戏菜单右侧的玩家列表中可见，一定程度上可反映出玩家的游戏阅历。部分成就甚至能让你得到角色装扮。

Comet 生存服务器配备有**众多资源包**，以提升玩家的游戏体验，包括译名修正资源包、独家唱片包、背景音乐包等资源包。我们也会按照玩家要求添加资源包。通过这个服务器基础，你可以其他玩家共享媒体资源，并且能够举办更丰富的活动，甚至多整点儿活。

无论你是一个建筑大师、红石工程师还是冒险/探险家，Comet 生存服务器都将为你提供一个完美的舞台。用你的创造力建造壮丽的城市、庞大的机械装置，或者探索世界各地的村庄或遗迹、勇闯危险的深黑古城，一切都取决于你的想象力。

最后欢迎各位玩家来到这个服务器，和我们一起参与建设。我们会尽自己所能为玩家创造良好和谐的游戏环境，感谢大家的支持。

### 服务器菜单

### 服务器活动
<div align="center">
	<img src="https://cdn.ipfsscan.io/weibo/mw690/008EsglKly1idk5m2ybgtj31hc0u01kx.jpg" width="500x">

我们会不定期在这里举办玩家活动并送出大量福利。

### 礼包与兑换码系统
<div align="center">
	<img src="https://cdn.ipfsscan.io/weibo/mw690/008EsglKly1idk5mcxvfxj31hc0u0qv5.jpg" width="500x">
</div>
我们会不定期地在QQ群内发放兑换码，发放的形式非常创新。我们大多数时候会以题目的方式来拟兑换码，通过让玩家做题、解题并按照要求来得到兑换码，玩家在得到兑换码后可进入游戏尝试领取神秘奖励。

### 特色资源包
<div align="center">
	<img src="https://cdn.ipfsscan.io/weibo/mw690/008EsglKly1idk5mj0c9tj31hc0u0kjl.jpg" width="500x">
</div>
在不改变游戏行为的情况下，它可以为服务器提供很多东西，包括但不限于唱片、更好的译名，甚至是背景音乐和颗播放的录音!（当然，为了冒险家们体验更纯净的生存玩法，我们没有在生存服务器添加行为包等影响原版游戏太大的内容）
