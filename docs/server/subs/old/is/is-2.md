# Comet 空岛服务器 <Badge type="info" text="二周目" />
> 开服时间：2024.1.28 ~ 2025.1.29，历时 367 天
:::tip
以下所有内容只适用于 Comet 空岛服务器**二周目**。
:::

## 简介
Comet 空岛服务器是本群组服的子服务器之一，目前只能通过生存服跨服进入。该服务器的主要运营由 Yhrfi 和 kongtou 负责。

这里提供纯净且有趣的空岛生存体验，新玩家仅需打开菜单即可创建自己的空岛。

我们有多个初始空岛供玩家选择，无论是经典的、物资齐全的草方块空岛，还是硬核的、几乎没有物资的石头空岛，我们都包括在内，玩家创建空岛的时候可根据个人喜好自行选择。

除此之外，这里还具有许多硬核的游戏措施（不然玩家总是觉得没事儿干），等着每一位玩家去发现。欢迎每一个有志之士来挑战我们的空岛~

除去主城（丛林生物群系），无论在世界的哪个角落，均为森林生物群系，只要有草方块即可刷出动物。

下界和末地是正常与完整的。

### 系统商店与玩家集市
服务器配备有特别全面的商店，如果玩家们有很急缺的物品，或者想得到一些原版空岛玩法获取不到的物品，可以上这里购买；如果有支持回收的物品，可以上这里回收。除了这个我们还有玩家集市，玩家可自行创建线上商店并且可以去其他玩家的商店买东西。

### 空岛等级制度
空岛等级是玩家建设空岛的动力，随着家园的不断壮大，玩家的空岛等级会不断上升。
玩家的空岛等级会显示在聊天行和排行榜中。
<div align="center">
	<img src="https://cdn.ipfsscan.io/weibo/mw690/008EsglKly1idk59dsvyvj3280190hdu.jpg" width="500x">
</div>

### 传送系统
每个玩家都可以给自己的空岛设立传送点，还可设置成公开传送点，其他玩家可传送至你的岛屿。我们还支持玩家间传送，但是会耗费玩家大量的经济。
