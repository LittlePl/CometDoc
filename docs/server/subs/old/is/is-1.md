# Comet 空岛服务器 <Badge type="info" text="一周目" />
> 开服时间：2023.2.1 ~ 2024.1.28，历时 361 天
:::tip
以下所有内容只适用于 Comet 空岛服务器**一周目**。
:::

在 Comet 空岛服务器中，我们为您提供**纯净且有趣的空岛生存体验**。

Comet 空岛服务器具有**多个初始空岛**供玩家选择，每一个空岛具有的资产都是各不相同的，这决定着玩家生存的难度。玩家仅需做好选择，然后服务器就会选择一个位置为玩家创建空岛。

Comet 空岛服务器设立有**空岛等级制度**。空岛等级是玩家建设空岛的动力。在这个服务器中，玩家的目标就是不断收集资源、建设家园，通过不断地努力和合作来成就自己的事业。随着家园的不断壮大，玩家的空岛等级会不断上升。
玩家的空岛等级会显示在聊天行和排行榜中。

在 Comet 空岛服务器中，拥有的自然资源非常有限。当你为资源问题而烦恼时，不必担心，我们为你准备了**商城系统**。保持每日签到，获得足够的钱数就能够在商城购买物品。服务器还支持玩家间的经济交流，玩家可自行创建线上商店并且可以去其他玩家的商店买东西。

在游玩过程中遇到了困难？比如唯一的岩浆变成了黑曜石？？或者想换一个空岛玩玩？不要紧，我们贴心的为你准备了**服务器帮助页面**，您可以在这里获取帮助。在服务器菜单中可以找到它。
