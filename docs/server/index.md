# Comet 陆上彗星服务器
## 📃 简介
Comet 陆上彗星服务器，是一个我的世界国际基岩版服务器，创办于2023年2月，其管理层成员均有4年以上开服经历，在2022年就有过合作。

服务器使用 BDS + LeviLamina 开设，是一个群组服务器，开设生存服务器、空岛服务器、小游戏服务器等子服务器，但我们仍然以原汁原味的原版生存服务器为主。

服务器包含众多有利于玩家生存的插件，还会加入一点特色设定（如精英怪）来丰富玩家体验。服务器也会在假期发布多个招新视频，视频内容主要以服主的视角，与其他玩家共同生存，遇到的奇特经历为主。

服务器最近还开设了Java服务器，由服务器玩家强力驱动，服务器管理员负责代理，是我们在Java版MC开服领域的一个新的尝试。

## 🚲 开始加入服务器
### 1. 加入QQ群
**输入群号**或**扫码**，**申请加入QQ群**，进群途径可在**服务器官网**获取。加入群聊后，您将收到来自服务器Bot的若干提示，包括：
- **欢迎语**
- **服务器目前版本和支持的版本**
- **绑定白名单的提示**
- **人机验证码**（重要）

### 2. 进行人机验证
在群聊内按照提示直接发送您的**人机验证码**，验证成功后，您会收到验证成功提示。

### 3. 绑定白名单
在群聊中发送 `绑定<游戏名>` 进行白名单绑定，其中 `<游戏名>` 更换为你自己的游戏名。注意消息中不要附带额外的符号（如 `<>` `""` 等），且游戏名需要区分大小写。
:::warning ✅ 为什么要审核？
白名单如今已成为在线验证服务器的常规操作。审核机制为我们提供了一个筛选目标玩家的途径，这有助于我们更好地建设服务器社区。
:::

### 4. 获取服务器IP端口
打开群聊的群公告页面，找到以 `❗IP请查看这里！` 为开头的**置顶群公告**，记住（或复制）里面的**IP**和**端口**。

### 5. 启动我的世界
确保你已经安装了正确版本的我的世界游戏客户端。
:::warning 💔 注意您的游戏版本
若您的版本和服务器不对应，或服务器不支持您的版本，您将不能加入服务器。在这种情况下，您可以等待服务器支持或更新至您的版本，或考虑重装您的游戏至支持的版本。
:::

### 6. 添加服务器
点击 **“游戏”** ，然后点击 **“服务器”** ，点击 **“添加服务器”** 按钮，然后输入您获取到的服务器的IP和端口。服务器名称填入你容易记住的名称即可。

### 7. 开始游戏
点击"完成"，然后选择我们的服务器，点击"加入服务器"。
:::warning 注意
进服需下载约50MB的资源包，这些资源包对服务器玩法完全没有影响，请放心下载。
:::
