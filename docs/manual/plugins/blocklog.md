欢迎使用 BlockLog！这个插件会默默记录你周围发生的方块变化、物品存取等操作。当你怀疑有人动了你的箱子、想查查某个钻石矿是谁挖的，或者只是好奇附近发生了什么，下面的指令能帮你快速找到答案。

:::warning 注意
你只能**查询**历史，不能回档或修改记录。如果需要恢复方块或物品，请联系管理员。
:::


## 可用指令一览

| 指令 | 作用 |
|------|------|
| `/bl help` | 查看帮助和参数说明 |
| `/bl l [参数]` | 查询历史记录（支持各种筛选） |
| `/bl i` | 开启/关闭**监察模式**，点击方块立刻看记录 |
| `/bl status` | 查看插件运行状态（在线人数、记录总数等） |

## 查询历史记录 `/bl l`

这是最常用的命令，可以帮你找出“谁在什么时候对某个方块做了什么”。

### 基本用法
直接输入 `/bl l`，会查询你周围 **10 格半径** 内最近的所有方块变动记录（最多显示全部，翻页查看）。

### 常用参数
你可以添加参数来精确筛选，参数之间用空格隔开，顺序无所谓。

| 参数 | 说明 | 举例 |
|------|------|------|
| `u:玩家名` | 只看某个玩家的操作 | `u:Steve` |
| `t:时间` | 限定多久之内（或多久之前） | `t:30m`（30分钟内）、`t:2h`（2小时内） |
| `r:半径` | 搜索半径（格数） | `r:50`（周围50格） |
| `a:动作` | 只看某种类型的操作 | `a:-block`（破坏方块）、`a:container`（容器变动） |
| `i:方块名` | 只看包含某些方块或物品的记录 | `i:diamond`（含“diamond”的方块） |
| `e:方块名` | 排除某些方块或物品的记录 | `e:stone`（去掉石头相关记录） |

:::warning 注意
 方块名和物品名可以简写，例如 `diamond_ore`、`chest`，不用写 `minecraft:` 前缀。多个名字用逗号分隔，如 `i:stone,dirt`。
:::

::: info 你的权限
- 查询半径最大 **200 格**（超过会自动缩小）。
- **不能** 使用 `u:玩家名` 过滤，只能查看所有玩家的记录（但可以通过 `a:`、`i:`、`e:` 等条件缩小范围）。
- 若需要跨更大范围搜索或按玩家名查询，请联系管理员。
:::

### 参数详解

#### 时间格式 `t:`
- `10s` – 10秒
- `5m` – 5分钟
- `2h` – 2小时
- `1d` – 1天
- `1w` – 1周
- 也可组合：`1h30m` 表示1小时30分钟前到现在

#### 动作类型 `a:`
- `a:block` – 所有方块变动（放置 + 破坏）
- `a:+block` – 只查放置方块
- `a:-block` – 只查破坏方块（包括爆炸）
- `a:container` – 容器物品变动（箱子、熔炉等）
- `a:inventory` – 玩家背包变化（你自己或别人的背包操作）
- `a:+item` – 捡起物品
- `a:-item` – 丢出物品
- `a:liquid` – 液体反应（水岩浆生成石头、黑曜石等）

#### 包含与排除 `i:` / `e:`
- 支持部分匹配：`i:diamond` 会匹配钻石矿、钻石块、钻石剑等所有包含 “diamond” 的物品。
- 多个名称用英文逗号隔开，**不要加空格**。

### 分页与翻页
查询结果每页显示 **10** 条。聊天栏底部会提示页码。  
要查看下一页，直接输入 `/bl l 2`（数字代表第几页）。  
**注意**：翻页时无需重新输入参数，插件会自动记住你上一次的查询条件，直到你执行新的查询。

## 监察模式 `/bl i`

开启监察模式后，你**点击方块（破坏或放置）** 时，聊天栏会自动显示该方块位置最近 **5** 条操作记录。就像随身携带一个“方块历史扫描器”。

- 开：`/bl i`
- 关：再次输入 `/bl i`

适合实时巡查、跟踪可疑行为，或检查某个箱子刚才被谁碰过。

## 查看状态 `/bl status`

输入 `/bl status` 可以查看：
- 插件是否正常运行
- 一共记录了多少条操作
- 当前在线玩家数
- 事件记录是否开启

## 实用示例

1. **想知道谁在这附近挖走了钻石矿**  
   `/bl l i:diamond_ore a:-block r:30 t:1h`  
   （搜索周围30格内1小时内所有破坏钻石矿的操作）

2. **看看这个箱子最近被谁动过**  
   开启监察模式 `/bl i`，然后打开箱子或破坏旁边的方块，聊天栏会立刻显示记录。

3. **查看除了石头之外的方块变动**  
   `/bl l e:stone a:block r:20`

## 注意事项

- 如果你发现重要物品丢失或方块被破坏，**及时截图记录**并联系管理员，附上你查询到的结果。
- 命令中的参数（如 `u:` `t:`）全部使用**英文冒号**，不要加空格。
- 查询范围太大会导致信息很多，建议先用时间 `t:` 或半径 `r:` 缩小范围。
- 插件记录的是服务器时间，显示的时间差（如“5分钟前”）基于你的系统时钟，可能会有细微误差。
